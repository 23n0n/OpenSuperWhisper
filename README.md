# fleet-state — the agent records for the OpenSuperWhisper fork

A snapshot of the first-mate working state, committed so it stops living on a single disk. It is deliberately
**not** on the code branches: `main` and `feat/local-translate-tone` hold the app, this branch holds the records.

```
fleet/    the first-mate home: state/tasks.json (task ledger), data/<id>/launch-brief.md, data/<id>/report.md,
          data/<id>/status.log, data/FLEET-STATE.md (chronological source of truth), data/RESUME.md (handoff)
docs/     voice-keyboard-fork-plan.md, voice-keyboard-study.md
archive/  opensuperwhisper-20260924.bundle (thin bundle: delivery + fm branches), fleet-records-20260924.tgz,
          all-local-branches-20260924.bundle (every local branch at snapshot time), local-branches-20260924.txt
```

Snapshot taken 2026-09-24 from `/Volumes/home/zenon/Projects/OpenSuperWhisper-fork/` with the delivery branch at
`23d873a`. Refresh it — the live records stay outside git, this branch is a copy:

```shell
./sync.sh "fleet records: <what changed>"
```

`sync.sh` copies `../fleet`, `../docs` and `../archive` over the snapshot, re-bundles every local branch, commits
and pushes. Nothing else in this branch is generated by hand.

**Redaction.** The live records stay intact outside git; this published copy has the captain's own dictation and
the model outputs produced from it replaced with `<redacted: …, N chars>` markers — `redact.py` lists the exact
literals and `sync.sh` runs it after every copy, so a refresh cannot reintroduce them. The measurement structure
(what was compared, the model, the result) is preserved; only the verbatim speech is not.
